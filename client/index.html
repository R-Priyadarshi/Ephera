Zero-memory data movement infrastructure

Move sensitive data peer-to-peer. Leave no retained trace.

Ephera is not cloud storage. It is a live transport engine that streams encrypted payloads directly between peers and does not preserve transfer history.

Zero-Memory Core

No DB writes, no file cache, no transfer history. Session data exists only while the runtime is alive.

Trust-Minimized Path

Data flows directly between peers. Signaling only introduces endpoints and then steps out of the payload path.

Abort-Safe Semantics

Abort is explicit and terminal. Partial completion is not misreported as success.

Concurrency Discipline

Transfers are isolated by session IDs with deterministic routing and bounded memory behavior.

How Ephera Operates

  1. 1. Session Initiation Host creates a room and issues an invite package (link, key, and optional passphrase snapshot).
  2. 2. Peer Handshake Receiver joins, signaling coordinates WebRTC negotiation, and peers establish direct channel.
  3. 3. Streamed Transfer Sender streams chunks under backpressure control. Receiver chooses save folder or discard mode.
  4. 4. Deterministic Teardown END/ABORT finalizes session lifecycle; no persistent transfer state remains in Ephera.
